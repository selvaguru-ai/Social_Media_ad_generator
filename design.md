# Design log

## 2026-08-13 — dashboard, Cobalt

- Product: operator dashboard over the existing prospect-to-pitch pipeline
- Audience: growth operators reviewing leads and gating outreach
- Use: scan a funnel, pick a lead, approve a pitch
- Tone: quiet, precise
- Theme: Cobalt (cool light paper, Space Grotesk + Inter, electric cobalt)
- Nav: N3 side-rail
- Footer: Ft2 inline status
- Diversification vs prior: first dashboard surface; no prior web UI

## 2026-08-14 — Lumen night foundry restyle

- Audience: the same operators, after hours, scanning then deciding
- Use: unchanged — funnel, lead, approval
- Tone: atmospheric foundry, not a SaaS admin
- Theme: Lumen (cool-violet night paper, Instrument Serif lowercase headlines, Geist, JetBrains Mono labels, molten-brass accent, coral verb landmark)
- Nav: N5 floating pill (solid paper, no glass)
- Footer: Ft5 statement line
- Diversification vs Cobalt: dark vs light; serif vs grotesk; brass vs cobalt; N5 vs N3; one filament-chamber apparatus vs none
- Constraint honored: no backdrop-filter; apparatus is a chamber with real scores, not a glowing orb; three-stat row only when three honest numbers exist
